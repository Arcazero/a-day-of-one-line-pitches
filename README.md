One original sentence that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun — an entry for make.fun's "A Day of One-Line Pitches" bounty ($5 in USDC).

## The pitch

> Tell the app idea you have been carrying around to an AI agent on make.fun in plain words and it will build you a working first version today — no code, no cost to try, and you keep what it makes.

196 characters, one sentence. The full line also lives in `pitch.txt`.

## Run it

```sh
python3 main.py
```

`main.py` writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
